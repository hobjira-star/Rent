**ประเด็นที่ขอให้ทนายดูเป็นพิเศษ**
1. ค่าปรับคืนช้าและเพดานความรับผิดรวม (ข้อ 6–8 ของสัญญา) — ทนต่อ ป.พ.พ. ม.383 และ พ.ร.บ.ข้อสัญญาที่ไม่เป็นธรรมหรือไม่
2. ข้อ "ไม่ใช่ชุดตัวจริงถือเป็นการไม่คืน" และระยะเวลาตรวจ 3 วันทำการ (ข้อ 9)
3. ใบตรวจสภาพที่ลงชื่อสองฝ่ายใช้เป็นบันทึกตาม ป.พ.พ. ม.561 ได้หรือไม่
4. ผู้เช่าอายุต่ำกว่า 20 ปี และผู้ปกครองเป็นคู่สัญญา (ข้อ 13)
5. ขั้นตอนทวงถามให้ตรง พ.ร.บ.การทวงถามหนี้ (ข้อ 10) และการแจ้งความร้องทุกข์
6. ประกาศความเป็นส่วนตัว: ฐานทางกฎหมาย อายุการเก็บ การส่งข้อมูลไปเก็บที่สิงคโปร์ การถ่ายรูปบัตรแบบปิดทับ
7. คำว่า "เงินประกันชุด" แทน "มัดจำ" ในสัญญา
