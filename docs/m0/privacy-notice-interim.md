# ประกาศความเป็นส่วนตัว (ฉบับชั่วคราว)

> ร่างเพื่อให้ทนายตรวจ · ฉบับ 0 · ใช้ช่วง M0 และปรับเป็นฉบับเต็มก่อนเปิดให้ลูกค้าจองผ่านเว็บ

**ผู้ควบคุมข้อมูลส่วนบุคคล:** [ชื่อร้าน / ชื่อเจ้าของ] ที่อยู่ [__________] ติดต่อเรื่องข้อมูลส่วนบุคคล: [อีเมล / LINE / โทร]

## 1. ข้อมูลที่เราเก็บ

| ข้อมูล | เก็บจากใคร |
|---|---|
| ชื่อ–นามสกุล เลขบัตรประชาชน วันเกิด ที่อยู่ตามบัตร ที่อยู่ปัจจุบัน | คุณกรอกเอง แล้วร้านตรวจกับบัตรตัวจริง (ร้านดูบัตรแล้วคืน ไม่เก็บบัตร) |
| รูปบัตรประชาชน **ที่ปิดทับศาสนาและหมู่เลือดแล้ว** | ร้านถ่ายตอนส่งมอบ |
| รูปตอนส่งมอบที่เห็นคุณถือชุด | ร้านถ่ายตอนส่งมอบ |
| เบอร์โทรศัพท์ LINE ID | คุณ |
| เลขบัญชีธนาคารและชื่อบัญชีสำหรับรับเงินประกันคืน · ชื่อผู้โอนเงิน · เลขท้ายบัตรและชื่อบนบัตร (ถ้าจ่ายด้วยบัตร) | คุณ ธนาคาร และผู้ให้บริการรับชำระเงิน |
| สัดส่วนร่างกาย (ส่วนสูง อก เอว สะโพก) — เฉพาะเมื่อคุณเลือกใช้การเช็กไซซ์ | คุณ |
| รูปและวิดีโอของชุดตอนส่งมอบและรับคืน · ประวัติการเช่า การชำระเงิน การคืนชุด และข้อความที่ติดต่อกับร้าน | ร้าน |

เราไม่เก็บเลขหลังบัตรประชาชน (laser code) และไม่ใช้ข้อมูลศาสนาหรือหมู่เลือด

## 2. ใช้ทำอะไร และฐานทางกฎหมาย

| วัตถุประสงค์ | ฐานทางกฎหมาย (พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562) |
|---|---|
| ทำและปฏิบัติตามสัญญาเช่า: ส่งมอบชุด รับคืน คืนเงินประกัน | สัญญา (ม.24(3)) |
| ยืนยันตัวตน ป้องกันการทุจริตและการไม่คืนชุด ติดตามทวงคืน ใช้เป็นหลักฐานในข้อพิพาทหรือการดำเนินคดี | ประโยชน์โดยชอบด้วยกฎหมาย (ม.24(5)) และการก่อตั้งหรือใช้สิทธิเรียกร้องตามกฎหมาย |
| บัญชีและภาษี | หน้าที่ตามกฎหมาย (ม.24(6)) |
| ส่งข่าวสารและโปรโมชัน | ความยินยอม — ขอแยกต่างหาก ไม่ให้ก็เช่าได้ตามปกติ |

## 3. เก็บนานเท่าไร

| ข้อมูล | ระยะเวลา |
|---|---|
| รูปบัตร (ปิดทับ) และรูปตอนส่งมอบ | ลบ 30 วันหลังการเช่าสิ้นสุดและคืนเงินประกันแล้ว |
| รูปและวิดีโอตรวจสภาพชุด | 12 เดือนหลังการเช่าสิ้นสุด |
| ชื่อ เลขบัตร ที่อยู่ ประวัติการเช่าและการชำระเงิน | ตามระยะเวลาที่กฎหมายบัญชีและภาษีกำหนด [ให้ทนาย/นักบัญชีระบุ] |
| ทุกรายการข้างต้น | **หยุดนับและเก็บต่อ** ระหว่างมีข้อพิพาท ชุดยังไม่ถูกคืน หรือมีหนี้ค้างชำระ จนกว่าเรื่องจะจบ |
| แบบฟอร์มกระดาษ | เก็บในตู้ที่ล็อกได้ และทำลายตามกำหนดเดียวกัน |

## 4. เปิดเผยให้ใคร
- ผู้ให้บริการรับชำระเงิน ธนาคาร และผู้ให้บริการส่งข้อความ (LINE, SMS) เท่าที่จำเป็นต่อการให้บริการ
- ผู้ให้บริการเก็บข้อมูลบนคลาวด์ ซึ่งเก็บข้อมูลที่ **ประเทศสิงคโปร์** [ทนายระบุฐานและมาตรการคุ้มครองตาม ม.28–29]
- ทนายความ เจ้าหน้าที่ตำรวจ หรือศาล เมื่อมีการไม่คืนชุด ข้อพิพาท หรือเมื่อกฎหมายกำหนด
- เราไม่ขายข้อมูลของคุณ และ **ไม่เปิดเผยชื่อหรือรูปของผู้เช่าต่อสาธารณะ**

## 5. สิทธิของคุณ
ขอเข้าถึงหรือขอสำเนา ขอแก้ไข ขอลบ ขอระงับการใช้ คัดค้านการใช้ ขอโอนย้ายข้อมูล และถอนความยินยอม (เฉพาะเรื่องที่ใช้ความยินยอม) — ติดต่อช่องทางด้านบน เราจะตอบภายใน 30 วัน สิทธิบางข้ออาจใช้ไม่ได้ระหว่างที่ยังมีสัญญาเช่า ข้อพิพาท หรือหนี้ค้าง และคุณร้องเรียนต่อสำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคลได้

## 6. ความปลอดภัย
ข้อมูลบัตรเก็บแบบเข้ารหัส เฉพาะเจ้าของร้านและพนักงานที่ได้รับมอบหมายเปิดดูได้ และทุกการเปิดดูถูกบันทึก หากเกิดเหตุข้อมูลรั่วไหล เราจะแจ้งสำนักงานฯ ภายใน 72 ชั่วโมงตามกฎหมาย
