# Rent — แพลตฟอร์มเช่าชุด

เว็บแอปสำหรับปล่อยเช่าชุด (ต่อยอดเป็นแอปมือถือภายหลัง) พัฒนาเป็น 3 เฟส

| เฟส | เป้าหมาย |
|---|---|
| 1 | ปล่อยเช่าชุดของตัวเอง พร้อมระบบกันชุดหาย ขั้นตอนเช็คของเข้า–ออก และรายงานหลังบ้าน |
| 2 | เปิดให้คนอื่นมาปล่อยเช่าบนแพลตฟอร์ม (marketplace) |
| 3 | บริการจัดการชุดให้ผู้ปล่อยเช่า โดยชุดมาอยู่ที่เรา คิดคนละเรตกับแบบจัดการเอง |

**สถานะ:** ขั้นวางแผน — ยังไม่มีโค้ด
