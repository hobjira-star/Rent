# Rent — แพลตฟอร์มเช่าชุด

เว็บแอปสำหรับปล่อยเช่าชุด (ต่อยอดเป็นแอปมือถือภายหลัง) พัฒนาเป็น 3 เฟส

| เฟส | เป้าหมาย |
|---|---|
| 1 | ปล่อยเช่าชุดของตัวเอง พร้อมระบบกันชุดหาย ขั้นตอนเช็คของเข้า–ออก และรายงานหลังบ้าน |
| 2 | เปิดให้คนอื่นมาปล่อยเช่าบนแพลตฟอร์ม (marketplace) |
| 3 | บริการจัดการชุดให้ผู้ปล่อยเช่า โดยชุดมาอยู่ที่เรา คิดคนละเรตกับแบบจัดการเอง |

**สถานะ:** เริ่มพัฒนารุ่น 1 ช่วง ก (ดู [docs/PLAN.md](docs/PLAN.md) หัวข้อ 7.1)

## โค้ด

| โฟลเดอร์ | อะไร |
|---|---|
| `packages/domain` | กฎธุรกิจแบบ pure function: เงิน (สตางค์) · วันที่ตามเวลาไทยและวันทำการ · เอกสารนโยบายพร้อมค่าเริ่มต้น · มัดจำตามระดับผู้เช่าและ band · เพดานความเสี่ยงรวม · ค่าปรับ ค่าเสื่อม เพดานความรับผิด การคืนเงินเมื่อยกเลิก · สถานะการจอง · เช็กไซซ์ |
| `db/migrations` | schema ของ Postgres: การกันจองซ้อนด้วย exclusion constraint · เลขบัตรหนึ่งเลขต่อหนึ่งบัญชี · มัดจำออกได้หลังด่านรับคืนเท่านั้น · เงินคืนของบัตรเข้าบัตรเดิม · บัญชีคู่ที่ต้องสมดุล · บันทึกเหตุการณ์ที่แก้/ลบไม่ได้ · บทบาท `app_runtime` |
| `db/test` | สคริปต์ตั้ง Postgres ชั่วคราวแล้วตรวจกฎข้างบน |
| `apps/web` | Next.js + Hono API (`/api/v1/health`, `/api/v1/quote`) และหน้าทดสอบถ่าย/อัปโหลดวิดีโอ `/dev/capture` (ไฟล์เก็บในเครื่องจนกว่าจะมี Supabase) |
| `docs/m0` | สัญญาเช่าชั่วคราว ใบตรวจสภาพ ประกาศความเป็นส่วนตัว การ์ดขั้นตอน — ร่างให้ทนายตรวจ |

```bash
pnpm install
pnpm test        # เทสต์ของ packages/domain
pnpm typecheck
pnpm db:test     # ต้องมี Postgres 16 ในเครื่อง หรือกำหนด DATABASE_URL
pnpm --filter @rent/web dev   # แล้วเปิด http://localhost:3000/dev/capture
```
